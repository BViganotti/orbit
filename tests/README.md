# Browser test

`playwright_studio.py` is the real-browser acceptance test. It requires Python
Playwright and a Chromium build, which are outside the Rust toolchain and are
therefore not a Cargo test.

```sh
cargo build --release -p orbit-studio
python3 tests/playwright_studio.py
```

What it checks:

1. the release binary starts with `--no-open --port 0`;
2. the printed `ORBIT_URL` loads and the health check succeeds;
3. six presets are present;
4. the Atlas rocket is selected, renamed and given a new payload;
5. server-side validation completes;
6. `lunar-atlas-100` runs to a successful lunar orbit;
7. the event table is populated;
8. the trajectory canvas contains drawn pixels;
9. the CSV export downloads with the expected header and rows;
10. no page JavaScript errors occurred.

It writes `tests/studio.png` as evidence. The screenshot is regenerated by each
run and is not used by any assertion other than visual inspection.
